# Whisker Line: LeCheddar's Revenge

A 2D point-and-click adventure game, in the style of *The Secret of Monkey
Island* / *Monkey Island 2: LeChuck's Revenge*, starring a small mouse who
has to brave the London Underground to rescue his sister from the legendary
rat crime boss **LeCheddar**.

- **[docs/architecture-guide.md](docs/architecture-guide.md)** — tech stack and project structure
- **[docs/argument.md](docs/argument.md)** — the story script/synopsis
- **[docs/development-guide.md](docs/development-guide.md)** — how to set up and run the game locally

## Quick start

```sh
python -m http.server 8000
```

Then open <http://localhost:8000>. No `npm install` required — see the
development guide for details.
